Schema Design Notes

  • All PKs are UUID v4 strings (VARCHAR 36) — generated with Python's uuid.uuid4() before INSERT
  • ENUM fields are stored as strings in MySQL; SQLAlchemy validates against the enum class at application level
  • Highlighted rows in students are intentionally denormalized for UX — see Normalization diagram for analysis
  • parents.user_id has both FK and UNIQUE constraints — enforces the 1:1 User ↔ Parent relationship
  • queue_entries.booking_id has UNIQUE constraint — a booking can only be in the queue once at a time
