Actor Descriptions

  • Parent — registers, adds children, books pickups, monitors live queue
  • Teacher — logs in with CNIC, views their section's students and queue, marks pickup statuses
  • Admin — system administrator, full access via separate /admin login, manages all entities
  • Teacher and Admin share the Login/Logout use cases with Parent (same /auth endpoints, different roles)
  • Admin is the only actor that can change booking statuses retroactively (Override Booking Status)
